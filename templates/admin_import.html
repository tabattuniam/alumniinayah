📋 Cara Import
1
Download Template
Download file template Excel, lalu isi data alumni sesuai kolom yang tersedia.
📄 Download Template Excel
2
Isi Data di Excel
Isi mulai baris ke-2 (baris ke-1 adalah judul). Kolom bertanda * wajib diisi. Jangan ubah urutan kolom.
3
Upload & Import
Upload file Excel yang sudah diisi di form sebelah kanan, lalu klik Import.
✅ Format tanggal lahir: YYYY-MM-DD (contoh: 2000-01-15)
✅ Kolom L/P: isi dengan huruf L (Ikhwan) atau P (Akhwat)
✅ No HP: awali dengan 0 (contoh: 081234567890)
✅ Foto tidak bisa diimport via Excel — upload satu per satu via Edit
